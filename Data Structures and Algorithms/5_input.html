    [Handwritten Notes Page]

    Brute force LCS(X, Y) \(|X| = n\) \(|Y| = m\)

    1. Enumerate all subsequences of \(X\) \(2^n\) subsequences \(\rightarrow O(2^n)\)

    2. Check every subseq \(Z \subseteq X\): is \(Z \subseteq Y\)? Example: \(B \ C \ A\) checked against \(A \ B \ R \ A \ C \ D \ B \ R \ A\) (Arrows match letters) \(\rightarrow O(n+m)\)

    Overall: \(O((n+m) \cdot 2^n)\) Assuming \(n \le m\): \(O(m \cdot 2^n)\)

    Header: LCS Optimal Substructure

    Theorem (Cormen et al. 2022, Theorem 15.1) Let \(X = \langle x_1, x_2, \ldots, x_m \rangle\) and \(Y = \langle y_1, y_2, \ldots, y_n \rangle\) be sequences, and let \(Z_k = \langle z_1, z_2, \ldots, z_k \rangle\) be an LCS of \(X\) and \(Y\). Then

    1. If \(x_m = y_n\), then \(z_k = x_m = y_n\) and \(Z_{k-1} = LCS(X_{m-1}, Y_{n-1})\). (Red box around “Z_{k-1}…” and note “recursive call”)
    2. If \(x_m \neq y_n\), then 2.1 either \(z_k \neq x_m\), in which case \(Z_k = LCS(X_{m-1}, Y_n)\) 2.2 or \(z_k \neq y_n\), in which case \(Z_k = LCS(X_m, Y_{n-1})\) (Red box around 2.1 and 2.2 conditions and note “2 recursive calls”)

    Slide 77

    Header: LCS: Bottom-Up Approach

    1 LCS_length(X, m, Y, n):
2   B = new 2D 1-indexed array (m by n)
3   C = new 2D 0-indexed array (m+1 by n+1)
4   for i = 1 to m
5     C[i, 0] = 0
6   for j = 1 to n
7     C[0, j] = 0
8   for i = 1 to m
9     for j = 1 to n
10      if X[i] == Y[j]
11        C[i, j] = C[i - 1, j - 1] + 1
12        B[i, j] = XY
13      else if C[i, j - 1] < C[i - 1, j]
14        C[i, j] = C[i - 1, j]
15        B[i, j] = Y
16      else
17        C[i, j] = C[i, j - 1]
18        B[i, j] = X

    [Image Description] On the right, a grid calculation for LCS(ABA, BA). Columns labeled B, A. Rows labeled A, B, A. Arrows indicate the “direction” of the value inheritance (diagonal for match, left/up for max). Result highlighted: LCS(ABA, BA)
