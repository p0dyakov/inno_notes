    Slide 3

    Pumping Lemma

    Given a regular language L there exists an integer (critical length) m such that for any string w ∈ L with length | w | ⩾ m we can find a split w = x y z such that:

    ▶ |x y| ⩽ m ▶ |y| ⩾ 1 ▶ x yⁱ z ∈ L for all i ⩾ 0

    Slide 4

    Pumping Lemma: Contrapositive

    Given a language L. If we show that for any integer m ⩾ 1 there exists a string w ∈ L such that |w| ⩾ m and for all possible splits x, y, z ∈ Σ* with ▶ |xy| ⩽ m ▶ |y| ⩾ 1 ▶ w = xyz

    there exists: i ∈ ℕ such that x yⁱ z ∉ L. Then, applying the Pumping lemma for regular languages, one can deduce that L is not regular.

    Slide 5

    Exercises

    Using Pumping lemma prove that L₁, L₂, L₃ and L₄ are not regular languages:

    1. L₁ = { v vᴿ | v ∈ Σ₁* } where Σ₁ = {a, b}
    2. L₂ = { v | v has an equal number of a’s and b’s } over Σ₂ = {a, b}
    3. L₃ = { aⁿ! | n ⩾ 0 } over Σ₃ = {a}
    4. L₄ = { aⁿ bˡ cⁿ⁺ˡ | n, l ⩾ 0 } over Σ₄ = {a, b, c}

    Pumping Lemma for Regular Languages

    • It is an essential property of all regular languages
    • All sufficiently long words in a regular language may be pumped, i.e. have a middle section of the word repeated an arbitrary number of times, to produce a new word that also belongs to the same language
    • The pumping lemma is used to prove that a particular language is non-regular
      • You will see a few examples in the tutorial and lab sessions
      • Here we see the most notable!

    Slide 37

    Pumping Lemma: formal statement

    • Given a regular language L, If x  L and |x|  |Q|, then there exists a q  Q and a w  I⁺ such that:
      • x = ywz
      • *(q₀,y) = q
      • *(q,z) = q’  F
      • *(q,w) = q
      • |yw|  |Q|
      • ywⁿz  L, n  0

    [Arrow graphic pointing to text box]: For languages that are not regular these conditions does NOT have to apply. However, some, at times, may apply.

    • This is the Pumping Lemma (one can “pump” w)

    A negative consequence of pumping lemma

    • Is the language L = {aⁿbⁿ | n > 0} recognized by some FSA?

    • Let us suppose it is, then:

    • Consider x = aᵐbᵐ, m > |Q| and let us apply the Pumping Lemma

    • There are only three possible cases to split a string with this simple pattern:

      • **x = ywz, w = aᵏ , k > 0 ====> aᵐ⁻ᵏ a⁽ᵏ*ʳ⁾ bᵐ  L, r : NO**
      • **x = ywz, w = bᵏ , k > 0 ====> aᵐ b⁽ᵏ*ʳ⁾ bᵐ⁻ᵏ  L, r : NO**
      • x = ywz, w = aᵏ bˢ , k, s > 0 ====> aᵐ⁻ᵏ (aᵏbˢ)ʳ bᵐ⁻ˢ  L r : NO

    42

    Slide 43

    First Case

    • In the first case, the internal string w is made only of “a”
      • we split the string x = ywz
      • where w = aᵏ and k > 0
      • y = aᵐ⁻ᵏ
      • z = bᵐ
      • Therefore yw = aᵐ⁻ᵏ aᵏ = aᵐ⁻ᵏ⁺ᵏ = aᵐ
      • x = ywz = aᵐ bᵐ
    • If the language is regular, then ywⁿz  L, n  0
      • **ywⁿz = aᵐ⁻ᵏ a⁽ᵏ*ⁿ⁾ bᵐ  L, r**
    • Does a string with this structure belong to L?
      • No, it is a string with more “a” then “b”

    43

    Slide 44

    Second Case

    • In the second case, the internal string w is made only of “b”

      • It is just symmetrical to the first case

    • **x = ywz, w = bᵏ , k > 0 ====> aᵐb⁽ᵏ*ʳ⁾ bᵐ⁻ᵏ  L, r : NO**

    • Does a string with this structure belong to L?

      • No, it is a string with more “b” then “a”

    44

    Slide 45

    Third case

    • In the third case, the internal string w is made both of “a” and “b”
      • we split the string x = ywz
      • where w = aᵏ bˢ and k,s > 0
      • y = aᵐ⁻ᵏ
      • z = bᵐ⁻ˢ
      • Therefore ywz = aᵐ⁻ᵏ aᵏ bˢ bᵐ⁻ˢ = aᵐ bᵐ
    • If the language is regular, then ywⁿz  L, n  0
      • aᵐ⁻ᵏ (aᵏbˢ)ⁿ bᵐ⁻ˢ  L r
    • Does a string with this structure belong to L?
      • No, it is a string with a prefix of “a”, a suffix of “b” and instances of “ab” in the middle
      • For example aaaababbbb

    Pushdown automata

    • Finite state automata can be enriched with a stack → Pushdown Automata (PDA)

    • PDAs differ from finite state machines in two ways:

      • They can use the top of the stack to decide which transition has to be made
      • They can manipulate the stack as part of performing a transition

    Acceptance, in general

    • Acceptance by “Final State”

      • Input is consumed and PDA is in a final state

    • Acceptance by “Empty Stack”

      • Input is consumed and stack is empty

    • Not equivalent for the deterministic pushdown automaton

    • They are equivalent for the non-deterministic pushdown automaton [Blue box]: We will see this later

    65

    Slide 66

    A little “hint”

    • The languages accepted by empty stack are:
      • the languages that are accepted by final state
      • have no word in the language that is the prefix of another word in the language
    • {L ∣ L is a context-free language} ∩ {L ∣ L is prefix-free}

    66

    Slide 67

    Proof Sketch

    • Suppose a PDA M accepts by empty stack language L and let x,y ∈ L, with x being a proper prefix of y (y=xz, z≠ε),

    • Start with x on input: M processes x, stack becomes empty at end of x, so acceptance happens at end of x

    • Now, if we continue with the rest of y (so y=xz, z≠ε), the PDA is at the same configuration as it was after reading x, but because it accepts by empty stack, after x, the stack is empty

    • If the stack is empty, and there is more input to read, the PDA cannot proceed

      • This means x would be accepted before reading the rest of y, contradicting y being accepted
