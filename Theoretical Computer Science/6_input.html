    A PDA, formally A PDA is a tuple \(\langle Q, I, \Gamma, \delta, q_0, Z_0, F \rangle\) – \(Q\) is a finite set of states – \(I\) is the input alphabet – \(\Gamma\) is the stack alphabet – \(\delta\) is the transition function – \(q_0 \in Q\) is the initial state – \(Z_0 \in \Gamma\) is initial stack symbol – \(F \subseteq Q\) is the set of final states 58

    Slide 59

    Transition function • \(\delta\) is the transition function • \(\delta: Q \times (I \cup \{\epsilon\}) \times \Gamma \to Q \times \Gamma^*\) – \(\delta(q, i, A) = \langle p, \alpha \rangle\) • Graphical notation: i,A/\(\alpha\) q p 59

    Slide 60

    Remarks • \(Q\), \(I\), \(q_0\) and \(F\) are defined as in FSAs • \(\delta\) is a partial function • \(Z_0\) is the initial symbol of the stack, but it is not essential – It is useful to simplify definitions • \(\delta(q, \epsilon, A) = \langle p, \alpha \rangle\) – An “\(\epsilon\) move” is a spontaneous move – \(\epsilon\) does not mean that the input is empty! – \(\epsilon\) means the input string is not changed by this transition — the input head stays in place – It is a move happening without consuming the input 60
