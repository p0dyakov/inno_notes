# Figure pipeline: matplotlib PNGs, no TikZ

TikZ is banned for article figures (Sept 2026): LLM-written tikz
coordinates eyeball intersections/tangencies and stack labels on lines.
Every figure is a **committed matplotlib PNG** generated by a script in
this directory.

## Layout

- `gen_<topic>.py` — one generator per article group (e.g. `gen_phy1.py`
  for Physics I/1). Each script writes into the article folder's
  `fig-mpl/` directory: `semester-4/<Course>/fig-mpl/<name>_mpl.png`.
- `mpl_pilots.py` — legacy pilots, superseded by per-topic generators.
- Article references: `![caption](fig-mpl/<name>_mpl.png){#fig-anchor}`.
  `render_changed.py` mirror-copies `*.png` page assets into `_site`,
  so committed PNGs deploy with no toolchain beyond matplotlib.

## Rules for every figure

1. **Computed geometry only** — solve intersections, tangencies,
   projections, fitted parameters (e.g. `brentq`, closed forms, least
   squares). Never hand-place a point that math can locate.
2. **No label collisions** — labels in whitespace; white chips
   (`bbox=dict(fc='white', ec='none', pad=1)`) where crowded; verify
   visually with `view_image` before committing.
3. **Style** — serif + STIX math, palette `#1f5fd0` blue / `#d62728` red /
   `#8a8a8a` gray; `dpi=150`; tight bbox. Site CSS caps height at 440px.
4. **Deterministic** — fixed seeds, no randomness; rerunning a script
   byte-reproduces its PNGs (modulo matplotlib version freetype deltas).

## Regenerating

```bash
python3 scripts/figs/gen_phy1.py   # Physics I/1
python3 scripts/figs/gen_phy2.py   # Physics I/2
python3 scripts/figs/gen_de.py     # Differential Equations 1+2
python3 scripts/figs/gen_ito.py    # Introduction to Optimization/2
python3 scripts/figs/gen_itp.py    # Introduction to Programming/1 (+1.ru)
```

Requires: `matplotlib`, `numpy`, `scipy` (CI: add to the pip-install line
in `.github/workflows/deploy.yml` if figures ever render server-side;
currently PNGs are prebuilt, so CI needs nothing new).
