# Theory section prompt

Write the Theory section (#### **1. Theory** plus #####/###### subsections).

- Teach from zero: define every term before using it.
- Cover every topic from the transcript table of contents; the TOC is the coverage checklist.
- Pedagogical order (what → why → how → pitfalls), not a transcript dump.
- Full paragraphs; bullets only when they genuinely improve clarity.
- **Bold** the first introduction of each key term.
- Math in LaTeX (`$...$` / `$$...$$`).
- Top-level summary subsections: `##### **1.1 ...**`; nested: `###### **1.1.1 ...**`.
- Headings are concise noun phrases, never questions.
- Correct transcript errors and fill missing logical links so a student can later solve the Practice tasks.
