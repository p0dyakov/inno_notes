# Часть 2: Теория (Theory)

Весь теоретический материал, формулы и методы, представленные на слайдах.

### 1. Разложение на простейшие дроби (Partial Fractions)

**Правила разложения:**
1.  **Степень:** Степень числителя должна быть хотя бы на единицу меньше степени знаменателя. Если степень числителя $\ge$ степени знаменателя, необходимо сначала выполнить деление многочленов.
2.  **Факторизация:** Знаменатель должен быть разложен на множители.

**Таблица форм разложения:**

| Вид множителя в знаменателе | Форма простейшей дроби |
| :--- | :--- |
| Линейный: $(x+a)(x-b)(x+c)$ | $\frac{A}{x+a} + \frac{B}{x-b} + \frac{C}{x+c}$ |
| Повторяющийся линейный: $(x+a)^3$ | $\frac{A}{x+a} + \frac{B}{(x+a)^2} + \frac{C}{(x+a)^3}$ |
| Квадратичный: $(ax^2+bx+c)(x+d)$ | $\frac{Ax+B}{ax^2+bx+c} + \frac{C}{x+d}$ |
| Повторяющийся квадратичный: $(ax^2+bx+c)x^2$ | $\frac{Ax+B}{ax^2+bx+c} + \frac{C}{x} + \frac{D}{x^2}$ |

### 2. Интегрирование тригонометрических функций

**Основные методы и тождества:**

*   **Квадраты функций:**
    *   $\int \cos^2 x \, dx$: использовать $\cos 2x = 2\cos^2 x - 1 \implies \cos^2 x = \frac{1+\cos 2x}{2}$
    *   $\int \sin^2 x \, dx$: использовать $\cos 2x = 1 - 2\sin^2 x \implies \sin^2 x = \frac{1-\cos 2x}{2}$
    *   $\int \tan^2 x \, dx$: использовать $1 + \tan^2 x = \sec^2 x$
    *   $\int \cot^2 x \, dx$: использовать $\cot^2 x + 1 = \csc^2 x$

*   **Степени $\cos^m x \sin^n x$:**
    *   Если $m$ или $n$ **нечетное** (но не оба): использовать $\cos^2 x + \sin^2 x = 1$ для замены четной части и внесения под дифференциал.
    *   Если $m$ и $n$ **четные**: использовать формулы понижения степени ($\cos 2x$).

*   **Произведения синусов и косинусов (Формулы произведения в сумму):**
    *   $\sin A \cos B = \frac{1}{2}[\sin(A+B) + \sin(A-B)]$
    *   $\cos A \sin B = \frac{1}{2}[\sin(A+B) - \sin(A-B)]$
    *   $\cos A \cos B = \frac{1}{2}[\cos(A+B) + \cos(A-B)]$
    *   $\sin A \sin B = -\frac{1}{2}[\cos(A+B) - \cos(A-B)]$

**Стандартные интегралы (Inverse Trig forms):**
*   $\int \frac{1}{\sqrt{a^2-x^2}} dx = \sin^{-1}(\frac{x}{a}) + C$ (Подстановка: $x = a \sin \theta$)
*   $\int \sqrt{a^2-x^2} dx = \frac{a^2}{2}\sin^{-1}(\frac{x}{a}) + \frac{x}{2}\sqrt{a^2-x^2} + C$
*   $\int \frac{1}{a^2+x^2} dx = \frac{1}{a}\tan^{-1}(\frac{x}{a}) + C$ (Подстановка: $x = a \tan \theta$)

### 3. Гиперболические функции (Hyperbolic Functions)

**Определения:**
*   $\sinh x = \frac{e^x - e^{-x}}{2}$
*   $\cosh x = \frac{e^x + e^{-x}}{2}$
*   $e^x = \cosh x + \sinh x$

**Основные тождества:**
*   $\sinh(-x) = -\sinh x$
*   $\cosh(-x) = \cosh x$
*   $\cosh^2 x - \sinh^2 x = 1$
*   $1 - \tanh^2 x = \text{sech}^2 x$
*   $\sinh(x+y) = \sinh x \cosh y + \cosh x \sinh y$
*   $\cosh(x+y) = \cosh x \cosh y + \sinh x \sinh y$

**Таблица интегралов:**
1.  $\int \sinh u \, du = \cosh u + C$
2.  $\int \cosh u \, du = \sinh u + C$
3.  $\int \text{sech}^2 u \, du = \tanh u + C$
4.  $\int \text{csch}^2 u \, du = -\coth u + C$
5.  $\int \tanh u \, du = \ln(\cosh u) + C$
6.  $\int \coth u \, du = \ln|\sinh u| + C$

### 4. Суммы Римана (Riemann Sums)

**Определение:**
Сумма Римана используется для аппроксимации площади под кривой (определенного интеграла).
Для функции $f(x)$ на отрезке $[a, b]$, разбитом на $n$ подынтервалов:

**Формулы:**
*   **Длина шага ($\Delta x$):** Если интервалы равны, $\Delta x = \frac{b-a}{n}$.
*   **Сумма:** $\sum_{i=1}^{n} f(x_i)\Delta x$.

**Выбор точки $x_i$ (Partition points):**
1.  **Left endpoint (Левый конец):** $x_i = a + \Delta x(i-1)$
2.  **Right endpoint (Правый конец):** $x_i = a + \Delta x(i)$
3.  **Midpoint (Середина):** $x_i = \frac{x_{left} + x_{right}}{2}$ (или $a + \Delta x(i - 0.5)$)
